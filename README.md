# CodeAlpha_Image-Gallery
A responsive and interactive Image Gallery web application built using HTML, CSS, and JavaScript. The project features a modern gallery layout, image navigation controls, lightbox view, hover effects, smooth transitions, and responsive design for an enhanced user experience across different devices.



## Overview

* Developed a responsive and interactive Image Gallery using HTML, CSS, and JavaScript.

* Designed a clean and visually appealing user interface to provide an enhanced image browsing experience.

* Implemented a responsive layout to ensure compatibility across desktop, tablet, and mobile devices.

* Integrated lightbox functionality to allow users to view images in an enlarged and focused view.

* Added next and previous navigation controls for seamless image browsing.

* Applied smooth transitions, animations, and hover effects to improve user interaction and visual appeal.

* Utilized JavaScript for DOM manipulation, event handling, and dynamic image navigation.

* Leveraged CSS to create a modern, attractive, and user-friendly design.

* Focused on improving usability, accessibility, and overall user experience.

* Demonstrated core front-end development skills, including responsive web design, interactive UI development, and JavaScript-based functionality.

## Key Features

* Responsive Image Gallery Layout
* Interactive Lightbox View
* Next and Previous Image Navigation
* Hover Effects and Smooth Animations
* Mobile-Friendly Design
* Dynamic User Interaction with JavaScript
* Clean and Structured Code Architecture
* Cross-Device Compatibility
